LIFTLOG 4.1 — LOCAL WORKOUT LOGGING

Open https://aha121coex.github.io/liftlog/ in Safari.
Tap Share > Add to Home Screen to install.

No Google account, OAuth setup, API key or subscription is required.
Log workouts offline after the initial online installation completes.
Use More > Share backup to send your history to ChatGPT, or save the file
in Files and attach it manually. Import returned routine JSON in More.

Export a backup before updates or switching phones. Close all old LiftLog
windows and reopen online to activate a new version. Keep the same Home
Screen installation and URL; do not clear Safari data to update.

README.md documents backup/recovery, AGENTS.md documents development rules.
